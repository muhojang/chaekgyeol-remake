# chaekgyeol-remake

[책결 그룹 프로젝트](https://github.com/boostcampwm2025/and03-chaekgyeol)를 개인 프로젝트로 재구현한 버전입니다.

## 프로젝트를 시작한 이유

### 1. 기존 프로젝트의 한계

기존 책결 프로젝트는 등장인물과 인상깊은 구절을 기록할 수 있는, 소설 장르에 특화된 독서 기록 기능을 제공했습니다.<br>
하지만 책에 해당 요소가 등장하지 않는 장르의 독서 기록에는 해당 기능을 사용하기 어색하다고 판단했습니다.<br>

이번 프로젝트에서는 모든 장르에 자연스러운 독서 기록 기능을 제공하는 형태로 재설계하여 위의 한계를 극복하고자 합니다.

### 2. 핵심 기능의 직접 구현 경험

그룹 프로젝트에서 구현된 핵심 기능 중 일부는 직접 구현하지 않았습니다.<br>
따라서 해당 기능의 설계 및 구현 과정을 깊이 이해하지 못하고, 제3자에게 직접 명료하게 설명하는 것이 어려웠습니다.<br>

이번 프로젝트에서는 핵심 기능을 처음부터 직접 구현하며 이를 해소하고자 합니다.

### 3. 개인 프로젝트로서의 도전

팀 프로젝트에서는 기획, 디자인, 컨벤션 등 개발 외적인 결정을 함께 논의했습니다.<br>
하지만 개발을 진행하며 처음 논의 시 미처 고려하지 못한 부분들이 생겨났고,<br>
기한 내 개발을 우선하다 보니 리뷰에서 지적된 사항도 미처 수정되지 못한 채 남는 경우가 있었습니다.<br>

이번 프로젝트에서는 기획, 디자인, 컨벤션 등 모든 결정을 직접 내리며 각 파트에서 제 자신의 기준을 확립하고<br>
향후 팀 프로젝트 진행 시 어떤 것을 규칙으로 정해야 하는지 파악하고자 합니다.
